# 02 — 옵션 입력 UX 개선 (자바스크립트)

**What to build:** 셀러가 상품 등록 화면을 열면 옵션 입력란이 처음엔 한 줄만 보인다. "+" 버튼을 누를 때마다 숨겨진 다음 줄이 나타나고(최대 5줄), 각 줄의 "×" 버튼으로 그 줄의 입력값만 비울 수 있다. 백엔드 폼 구조는 그대로다.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [x] `/products` 등록 화면을 처음 열면 옵션 입력 줄이 1개만 보인다(나머지 4개는 DOM에 존재하되 숨겨져 있음).
- [x] "+" 버튼을 누르면 숨겨진 줄 중 가장 앞의 것이 보인다.
- [x] 5줄이 모두 보이면 "+" 버튼이 비활성화된다.
- [x] 각 줄의 "×" 버튼을 누르면 그 줄의 그룹명·값 입력값이 비워진다. 1번째 줄은 계속 보이고, 2~5번째 줄은 다시 숨겨진다(다시 "+"로 불러올 수 있음).
- [x] 줄 추가/삭제는 페이지 새로고침 없이 자바스크립트로만 이뤄지며, 다른 입력값(상품명·가격 등)이 유지된다.
- [x] 백엔드로 제출되는 필드 이름·구조(`optionGroups[0..4].name`/`valuesText`)는 이전과 동일하며, 기존 옵션 조합 생성 로직과 그 테스트는 변경되지 않는다.
- [x] 옵션 값을 입력하고(1~5줄 아무 조합이나) 등록했을 때 조합이 올바르게 생성되는 기존 동작이 계속 통과함을 회귀 테스트로 확인한다(새 테스트가 필요하면 추가, 기존 `ProductCrudTest`가 계속 통과하는 것으로 충분할 수도 있음).
